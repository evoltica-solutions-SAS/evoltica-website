# docs/design/

> **Versión**: 1.0 · **Estado**: Active · **Última actualización**: 2026-07-07 · **Responsable**: Evoltica Solutions SAS

## Propósito

Espacio para artefactos y exploraciones de diseño que son más detallados o transitorios de lo que corresponde tener en [DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md) (que se mantiene como la especificación vigente y estable del sistema).

## Qué va aquí

- Exploraciones visuales/wireframes de una sección o página nueva antes de implementarse.
- Justificación detallada de un cambio visual puntual (p. ej. por qué se ajustó un espaciado o una animación específica).
- Auditorías de accesibilidad visual o de contraste con hallazgos detallados.
- Capturas o referencias de inspiración visual usadas como input de una decisión de diseño.

## Qué NO va aquí

- El sistema de diseño vigente (tokens, clases, reglas de uso) → eso vive en [DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md).
- La decisión formal de una paleta o identidad de marca → eso es un ADR, ver [ADR-005-Brand-Guidelines.md](../decisions/ADR-005-Brand-Guidelines.md).

## Convención de nombres

`AAAA-MM-DD-titulo-corto.md`, por ejemplo: `2026-09-02-exploracion-seccion-casos-exito.md`.

## Referencias
